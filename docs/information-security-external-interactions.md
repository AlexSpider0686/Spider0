# Реестр внешних информационных взаимодействий

Документ фиксирует внешние адреса и сервисы, к которым обращаются сайт и платформа `Project.Core™`, а также цель обращения, обязательность использования и состав потенциально передаваемых данных.

## Контекст

- В настоящее время ведется доработка сайта и платформы с учетом требований стандартов по информационной безопасности.
- Текущая рабочая среда разработки и хранения проекта использует GitHub.
- Параллельно ведется переход на отечественный репозиторий GitVerse и облачное хранилище Сбер.
- Отдельно разрабатывается собственный инструментальный контур для дальнейшей разработки взамен текущего использования CODEX OpenAI.
